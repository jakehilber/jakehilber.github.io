# GitHub portfolio site

This is a no-build static website designed for GitHub Pages.

## Publish it

1. Create a new GitHub repository, preferably named `<your-github-username>.github.io`.
2. Upload the contents of this folder (not the folder itself) to the repository root.
3. In the repository, open **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Replace the `#` in the GitHub header link inside `index.html` with your profile URL.

Your site will publish at `https://<your-github-username>.github.io`.
